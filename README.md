A short vertical GTA 6 clip demonstrating AI clip creation on make.fun, paired with a lightweight Node.js tool that copies VIDEO.json to the output directory for processing.

## Run it

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
